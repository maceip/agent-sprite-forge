# Agent Sprite Forge (Claude Code / Grok Claude-compat)

Grok reads this file automatically. Cursor Cloud Agents prefer `AGENTS.md`. Follow both the same way.

- Skills: `skills/generate2dsprite`, `skills/generate2dmap`, `skills/video2dsprite`
- Processors: `python scripts/forge.py --help`
- Runtime tool names: `docs/agent-runtime.md`
- Marketplace: `.claude-plugin/marketplace.json` and `docs/marketplace.md`

Install into Claude Code:

```bash
python scripts/install.py --target claude
```
